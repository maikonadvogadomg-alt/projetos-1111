# Modelo de CSR para certificado A1 PDJUD

**Modelo oficial de CSR para certificado A1 PDJUD/eProc TJMG** conforme padrões ICP-Brasil e OAB/MG:

## Comando OpenSSL Completo (PDJUD A1)
```bash
openssl req -new -newkey rsa:4096 \
  -keyout pdjud_private.key \
  -out pdjud_a1.csr \
  -nodes \
  -subj "/C=BR/ST=MG/L=Belo Horizonte/O='OAB - MG'/OU='Seccional MG'/CN='Nome do Advogado OAB/MG 123456'/serialNumber='MG123456'/emailAddress=advogado@oabmg.org.br" \
  -addext "subjectAltName=DNS:pdjud.advogado.mg.oab.org.br,DNS:eproc.tjmg.jus.br"
